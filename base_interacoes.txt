# BASE DE INTERAÇÕES: Cyberpunk: Edgerunners, temporada 1 (Netflix, 10 episódios)
#
# ESQUEMA DO REGISTRO (campos separados por um espaço em branco)
#   personagem1 personagem2 sinal ambiente episodio minuto
#   A linha logo abaixo de cada registro, iniciada por #, traz a descrição breve do evento,
#   que também serve de justificativa do sinal.
#   Rede não direcionada: a ordem de personagem1 e personagem2 não tem significado.
#
# CRITÉRIOS
#   Interação: conversa, ação dirigida ao outro (incluindo conflitos) ou ação conjunta em que os
#   dois agem juntos por um mesmo objetivo. Chamada em que os dois se respondem conta como
#   interação direta. Interação indireta não entra. Se uma pessoa dá uma ordem a vários e só um
#   responde, é um registro.
#   Início e fim: a cada mudança de cena ou de ambiente; quando um dos personagens sai da cena, a
#   interação termina.
#   Conversa prolongada: um registro por cena, mesmo com várias falas.
#   Eventos distintos: cenas diferentes do mesmo par geram registros separados. Se a mesma cena
#   muda de sinal, são dois registros do mesmo par e ambiente, com minutos diferentes.
#   Sinal, pelo efeito da ação sobre o outro personagem, de forma óbvia:
#     +  a ação ajuda o outro
#     -  a ação prejudica o outro (agressão é negativa mesmo que a vítima merecesse)
#     0  interação direta que não ajuda nem prejudica de forma clara
#   Sinal incerto: o caso fica de fora das análises de sinal.
#   Identificadores: NomeSobrenome, sem acento, espaço ou símbolo. Personagem sem nome recebe um
#   ID descritivo (ex.: DiretorAcademia).
#
